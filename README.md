## ⚡ Quick Start

**Step 1 — Open ChatGPT** (free at [chatgpt.com](https://chatgpt.com))

**Step 2 — Copy your first prompt:**

For reviews:
```
You own a [type of business]. A customer left this 5-star review: "[paste review]". Write a warm, personal response that thanks them specifically. Keep it under 80 words.
```

For social media:
```
You manage social media for a [type of business]. Write 5 Instagram captions about [your topic]. Each should be different in style (funny, professional, question-based, emotional, promotional). Include 3-4 hashtags.
```

**Step 3 — Customize and post.** That's it. You've just saved 10 minutes.
